# SURF 2026 poster

Files:

- `SURF2026_Poster.pptx` — editable source poster.
- `SURF2026_Poster.png` — rendered one-page preview for GitHub.

The poster presents the full SURF group project, including long-context m6A
prediction and multi-technology Bayesian integration. This repository focuses
on the benchmark, posterior-derived technology-error, feature-interpretation and
external-validation components. The poster was copied without editing sections
outside that repository scope.
