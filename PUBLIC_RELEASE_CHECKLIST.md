# Public-release checklist

The first GitHub repository should remain private. Before making it public, confirm:

- supervisor approval to release unpublished results;
- collaborator approval and authorship/attribution language;
- permission to expose internal file-path provenance;
- whether ConquerNet helper code may be redistributed;
- whether any figure or table is under manuscript embargo;
- replacement of internal server defaults with documented CLI examples;
- addition of an agreed software license;
- addition of a formal citation and contact address;
- a final secret scan and data-size audit.

No raw participant, clinical or credential data are intended for this repository.
