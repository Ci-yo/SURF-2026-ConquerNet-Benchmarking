# Public-release notes

This repository is a compact public research snapshot. The following safeguards were applied before the initial push:

- raw sequencing data, fitted models, per-site posterior matrices, OOF predictions and rank caches were excluded;
- no SSH keys, tokens, passwords or credential files were included;
- no tracked file exceeds GitHub's standard file-size limit; the editable poster
  is approximately 4.9 MB and all scientific results remain compact;
- obsolete Total>20, Vote and legacy-label result branches were excluded;
- the frozen benchmark contains ConquerBN, continuous IDR, RRA and Rank
  Product; superseded MeanProb summaries were excluded;
- negative IVT and perturbation findings were retained rather than selectively omitted;
- internal paths are included only as provenance and do not grant access to the source data.
- verified R object types and statistical meanings are documented separately
  from informal biological descriptions in `data_catalogue/OBJECT_CONTRACTS.md`;
- the full SURF group poster is included unchanged as PPTX plus a rendered PNG
  preview; unrelated poster sections were not edited for this repository update.

Items still requiring project-level decisions before a manuscript/software release include collaborator attribution, an agreed software license, a formal citation/contact address and confirmation that redistributed ConquerNet helper functions have the intended release status.

No raw participant, clinical or credential data are intended for this repository.
